# 标题生成是独立会话调用

ADR-0012 将首次标题 auxiliary 调用纳入主运行生命周期，是历史实现的决定；ADR-0037 提供一次性业务认领，ADR-0035 放宽跨度归属。本决定 supersede ADR-0012 中标题与主运行并行且同生命周期的部分，不改变 auxiliary 输出永不写入消息表、两个模型角色共用端点档案等约束。

**决定：**首条用户消息与 fallback 随主运行入口提交，但主运行不认领、调用、等待或投递标题。前端在首次 `RUN_STARTED` 后使用发送时的 `model_override` 快照调用 `POST /api/sessions/{session_id}/title`；独立 HTTP 调用从消息表读取首条用户消息，短事务一次性认领，再通过 `ModelPort` 无工具、固定 `low` 调用辅助模型。模型调用从开始计时总超时 30 秒。模型调用期间不占用业务事务；超时、取消、空输出与上游失败保留 fallback，不重新开放资格。

标题响应只报告实际业务标题及处理结果。标题跨度是会话级根跨度，记录实际模型和用量；模型结果与标题应用结果分开记录。观测独立事务故障不影响业务提交。新运行的 SSE、用量、跨度树和 `ended_at` 只对应主 ReAct；历史运行、标题跨度和统计原样保留，不重算。

**边界：**仅请求主运行的 API 客户端只得到 fallback。浏览器停止回答不取消标题，离开会话或页面取消标题请求；服务端监听 HTTP 断连并取消尚未完成的模型调用，退出独立客户端作用域。模型与断连同时完成时保留已取得的模型结果；取消与业务提交竞争时等待短事务结束，以已提交结果为准，用量按已取得的事实记录，不把未知用量填为零。取消后生成资格不重新开放；重复 POST 返回持久化状态，不等待或重试。服务端不保存完整模型配置、密钥或原始上游错误。进程意外退出后可能留下未闭合记录，不引入 lease、后台恢复或队列。

> **展示范围调整（2026-10-03）**：标题生成、观测写入和 `GET /api/sessions/{session_id}/title-generation` 查询均保留。仅移除会话列表的标题详情入口；不在当前位置展示辅助模型调用，后续其他页面的入口另行设计。
