# 系统提示词是运行配置，不是对话记忆

旧实现曾把两个模块级提示词常量在 import 时求值一次——服务跑一周，提示词里的"今天"还停在部署那天。改了就是改了：无版本、无对比、无回归，答不出"这条差回答是哪版提示词产生的"。

**决定：系统提示词是[运行](../../CONTEXT.md)的配置事实，不进消息表。**

[ADR-0001](./0001-messages-are-the-single-source-of-truth.md) 说消息表存"完整的模型视角序列"，那条指的是**对话记忆**。系统提示词不是任何人说过的话——它随日期与[努力档位](../../CONTEXT.md)逐次解析，同一会话里每轮都可能不同。入表就会在消息序列里放进一条每轮都在变的记录，于是"无损重建"当场要回答"重建用哪一版"，而这个问题没有正确答案：用当初那版是错的（用户看到的是今天的助手），用今天那版也是错的（那不是当初的序列）。

因此**重建函数产出的序列不含 system**。`agent/service.py` 在构造 Runner 时读出提示词，把"已解析的字符串 + [提示词版本](../../CONTEXT.md)"作为入参传进去；`AgentRunner` 依然纯（[ADR-0008](./0008-a-run-emits-domain-events-not-wire-frames.md)），它不知道提示词存在哪里，评测的 L2 回放喂一个字面量就能零网络零数据库跑完 Loop。版本标识随[运行事件](../../CONTEXT.md)带出，走的正是 ADR-0008 为层级标识定的同一条通路。

## 两条提示词合成一条

[ADR-0004](./0004-tools-are-capabilities-providers-are-implementations.md) 已用四档努力档位取代了"快速 / 深度"二分。若继续维持两份文本，四个档位就要映射到两份文本，出现档位与文本多对一的错配——而档位本来就要求评测分组冻结，届时无法归因差异到底来自档位还是来自文本。

**一条基础提示词 + 档位注入的软预算变量，让档位成为唯一自变量。**

同时整块删掉的东西：

- **两大段工具说明**——工具描述归 JSON Schema，两份真相迟早不同步。连同"你永远不应该连续执行两次提取"这类为已废工具写的绕坑指令一起删。
- **`Thought:` / `Action:` / `Observation:` 那套文本格式约定**——原生 tool calling 下它是死代码，模型不按它输出，我们也不按它解析。
- **"默认关注中国和亚洲地区"**——拍的，没有依据，且与"优先返回中文"重复施压。

**"优先返回中文"改为跟随用户消息的语言。** demo 公网完全开放，英文提问被强行中文回答是明显的坏体验。提示词模板本身保持中文——没有"中文指令导致 instruction-following 变差"的实测依据，没有依据就不动它。

## 变量只有两个

`date` 与 `step_budget`（步数[软预算](../../CONTEXT.md)——它不是工具参数，无处可去，只能走提示词；`max_results` 与 `search_depth` 的软预算由 JSON Schema 的 `maximum` / `enum` 表达，不在提示词里重复）。

**用 `string.Template` 的 `$var`，不用 `str.format`。** 提示词里迟早出现 JSON 示例的花括号，`str.format` 会当场炸。

**不把档位名本身作为变量。** "你现在是 high 档"这种标签模型无法正确解释，与软预算重复施压，还平白给评测多一维自变量。

## 被否决的方案

**系统提示词入消息表。** 严格读 ADR-0001 的"完整模型视角序列"确实该这么做，代价是上面那个无解的"重建用哪一版"，以及同一份文本在每个会话里按轮次复制。

**每档一条提示词（四条）。** 表面上让每档的措辞可以精调，实际是把一个连续量（做多少）拆成四份会各自漂移的文本。四份文本迟早在无关的地方产生差异，而评测跨档对比时无法区分那是设计还是漂移。

## 后果

- `prompts.py` 的模块级常量与 import 时求值整块删除。日期不再是"部署时的今天"。
- 系统提示词对终端用户**不可见、不可改**。可改会让每条 trace 的提示词都不同，评测基线当场失效——[ADR-0004](./0004-tools-are-capabilities-providers-are-implementations.md) 刚为同一个理由判了工具误选率死刑，不该在提示词上重犯。不可见则是可改被否掉之后的自然选择：一个看得见却改不动的输入框只会招来"为什么不让我改"。
- 提示词表归 `agent/`，`conversation/` 完全不碰提示词——它重建的是对话记忆，系统提示词不在它的职责里。
