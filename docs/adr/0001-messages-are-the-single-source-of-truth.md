# 消息表是对话记忆的唯一事实来源

[消息](../../CONTEXT.md#对话)表是对话记忆的唯一事实来源。 它存放完整的模型视角序列——user消息、assistant消息、tool返回结果 全部入表，每一轮从库里重建喂给模型的消息序列seq。

**[Agent 状态快照](../../CONTEXT.md#观测)挂在[运行](../../CONTEXT.md#对话)上，只写不读。** evals 的[回放](../../CONTEXT.md#测试与门禁)层需要它，调试也需要它，所以它必须存；但它是观测数据，**不是恢复源**。系统里没有 checkpointer 语义：没有 resume，没有 time-travel，一次运行中途失败就是重来一轮，而不是从快照续跑。

## 后果

- 消息按[会话](../../CONTEXT.md#对话)内显式 `seq` 排序，不靠时间戳——一次运行产出的多条消息时刻可能相同。
- 「存了完整序列」不等于「每轮把完整序列喂给模型」。历史[工具](../../CONTEXT.md#工具)结果会让 prompt 迅速膨胀，如何截断或摘要是另一个决策；存下来只是保住了选择权。
